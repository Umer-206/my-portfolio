## Project facts

- Repo: `d:\Projects\my-portfolio`, React 19 + Vite 8 + TS + Tailwind 4 (CSS-first `@theme`, no config file) + framer-motion + lucide-react.
- Design system: "Alexandria — High-End Editorial" per `DESIGN.md`. Light, serif-headline, no-hard-borders (ghost-border only), tonal surface layering, gradient primary CTAs.
- Multi-page structure now: `src/pages/<Page>.tsx` composed of section components in `src/components/<page>/`. Shared chrome in `src/components/layout/Navbar.tsx` + `Footer.tsx`, rendered once in `App.tsx` around whichever page is active.
- Old dark-theme single-page-scroll components (`src/components/About.tsx`, `Experience.tsx`, `Skills.tsx`, `Certifications.tsx`, `Education.tsx`, `Projects.tsx`, `FloatingCV.tsx`) are NOT imported anymore — kept on disk as content reference only, will be rebuilt page-by-page against their Stitch mockups when provided.
- Dev server: `npx vite --host 127.0.0.1 --port <N>`. Windows `EACCES` port blocks are common and shift over time — 5173 always blocked, 3000 was fine then also got blocked (2026-08-28). If a port EACCESes, just try another (4321 worked on 2026-08-28). Not a dependency issue.
- 2026-08-29: server kept dying with `EBUSY: watch '...public/...'` — Vite's fs.watch crashes the whole process on Windows when a file in `public/` is briefly locked (image editors, cloud sync, AV). Fix in `vite.config.ts` → `server.watch.usePolling: true, interval: 300`. (First tried `watch.ignored: public/**` but that stopped Vite serving newly-added public files without a restart — reverted.) Also: a public image added while the server is running may need a hard refresh; if it 404s as `text/html`, restart vite.
- Hero image: `public/11.png` (real portrait — white shirt/red tie, transparent bg), container `aspect-[4/5]`, `object-cover object-top scale-[1.5] origin-top -translate-y-[18%]` (source has big empty top — scale up + shift up so the person sits centered/large). Container bg is a dark→blue diagonal gradient `linear-gradient(135deg,#0d1b2a,#1b263b 50%,#1565c0)`, `rounded-2xl`, no ghost-border (was `bg-surface-dim`). (Prior: umerphoto.png, then briefly Education11.jpg collage — both still on disk.)
